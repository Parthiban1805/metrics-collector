# metrics-collector

This repository contains documentation on metrics collection and server monitoring.

## Contents

- `data-collection-frequency/`: Information on the frequency of data collection for various system metrics (CPU, RAM, Disk I/O, Network Traffic, etc.).
- `linux-server-monitoring-security/`: A comprehensive guide on Linux server monitoring and security visibility, covering tools like Netdata, auditd, Wazuh, ClamAV, and Fail2Ban.
- `platform-architecture/`: Complete architecture of the multi-tenant monitoring platform (VM metrics, AI usage, security), including the three-tier intelligence model (code, Jev, Claude), model comparison, and additional features.
